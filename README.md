# scRNA
Single-cell Omics: Decoding cellular heterogeneity, gene expression dynamics and disease mechanisms through computational transcriptomics.
Data preprocessing: Quality control, filtering, normalization and feature selection.
Cellular heterogeneity: Dimensionality reduction using PCA, UMAP and t-SNE, followed by cell clustering.
Cell-type annotation: Identifying cell populations using marker genes and reference datasets.
Differential expression: Discovering genes associated with specific cell types, conditions or disease states.
Pathway analysis: Interpreting biological pathways and gene regulatory mechanisms.
AI-driven single-cell analysis: Applying machine learning to cell-state classification, biomarker discovery and disease prediction.
Multi-omics integration: Combining scRNA-seq with epigenomic, proteomic and spatial transcriptomic data.
